# Platform Engineering

Claude Code plugin for platform engineering work: Kubernetes operations,
GitOps and CI/CD, infrastructure as code, observability, and cloud-native
platform design.

Status: scaffold — skills land next.

## Install

```
/plugin marketplace add BittahCriminal/plugin-hub
/plugin install platform-engineering
```

## Layout

```
.claude-plugin/plugin.json   # manifest
skills/<name>/SKILL.md       # one directory per skill
```
